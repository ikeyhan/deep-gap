# فونت‌ها — Yekan Bakh / Yekan

اپ برای فونت **یکان‌بخ (Yekan Bakh)** به‌عنوان فونت اصلی و **یکان (Yekan)** به‌عنوان جایگزین طراحی شده است (`fontFamily: 'YekanBakh'` در `lib/core/theme.dart`).

## فعال‌سازی
۱. فایل‌های فونت را در همین پوشه (`assets/fonts/`) قرار دهید با همین نام‌ها:
```
YekanBakh-Regular.ttf
YekanBakh-Medium.ttf
YekanBakh-Bold.ttf
YekanBakh-ExtraBold.ttf
Yekan.ttf
```
۲. در `pubspec.yaml` بخش `# fonts:` را از حالت کامنت خارج کنید.
۳. اجرا کنید:
```bash
flutter pub get
flutter run
```

پس از این کار، کل رابط کاربری به یکان‌بخ تغییر می‌کند. تا پیش از افزودن فایل‌ها،
اپ بدون خطا build می‌شود و از فونت پیش‌فرض سیستم استفاده می‌کند.

> یکان‌بخ توسط «فونت‌ایران / تنکو» منتشر شده است. لطفاً نسخهٔ فونت را از منبع
> رسمی و مطابق با شرایط لایسنس آن تهیه کنید. اگر به فونت آزاد نیاز دارید،
> «Vazirmatn» (لایسنس OFL) گزینهٔ خوبی برای جایگزینی است.
