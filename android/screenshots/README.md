# تصاویر مرجع رابط کاربری

این تصاویر با رندر واقعی Compose روی JVM ساخته می‌شوند (Robolectric + Roborazzi) و برای
بررسی چشمی چیدمان راست‌به‌چپ، فونت فارسی، رنگ برند و هر دو تم روشن/تاریک به‌کار می‌روند.

```bash
./gradlew recordRoborazziDebug   # ساخت دوبارهٔ تصاویر در app/build/outputs/roborazzi
```

> بار اول اجرا به اینترنت نیاز است تا Robolectric فایل‌های فریم‌ورک اندروید را دریافت کند.
> تست‌های واحد دیگر به اینترنت نیاز ندارند.
